# One Word From Grandma — make.fun entry

An entry for the make.fun competition **One Word From Grandma**.

`main.ts` (Node 22, stdlib only) writes exactly one word to
`$MAKEFUN_OUTPUT_DIR/entry.txt`: the word grandma would text about AI.
She has decided ChatGPT is a helpful lady called Chatty, and she texts
with caps lock permanently on — so the word arrives as she would send it.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

The program validates that the output is a single word within the
30-character cap and produces byte-identical output on every run.

The entry word is **CHATTY** (6 characters): ChatGPT, renamed by grandma
into a person and shouted kindly in caps lock, the way she texts
everything.
